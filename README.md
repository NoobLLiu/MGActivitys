# MGActivitys

StarCIty growth-value (成长值) tracking plugin for Paper 1.21.11. Tracks player activity, provides a leaderboard, and a growth-value shop.

- Name: MGActivitys
- Version: 1.0.1
- Main: `cn.gmzc.mgactivitys.MGActivitysPlugin`
- Depend: GMZCSkinCache
- Soft-depend: floodgate, GMZCTitles, FakePlayerManager

Build with `powershell -ExecutionPolicy Bypass -File build.ps1` (requires the StarCIty server runtime and its Java 25 JDK).
